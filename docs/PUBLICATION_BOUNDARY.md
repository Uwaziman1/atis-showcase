# Publication boundary

The full application is private. Public files are limited to the README, conceptual
architecture, case study, walkthrough, dated validation note, copyright notice and
two reviewed historical UI images. This repository starts with fresh Git history.

No full engine, detailed rule specification, test implementation, real journal,
database, environment file, credential, account information, execution log or backup
is published. This is a portfolio case study rather than a deployable trading service.
